签名私钥

未选择

Ed25519 私钥，JWK 格式。导入发布过此插件的私钥，或为新插件生成一个。

导出并妥善保存这个私钥后才能打包。插件以后的每个版本都要用它签名。

私钥只保存在当前页面，刷新后需要重新导入。私钥丢失或更换后，用户更新插件时会看到发布者变化，继续安装会删除旧插件的全部数据和权限。
